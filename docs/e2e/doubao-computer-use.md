# Doubao Computer Use 流程测试

运行：`npx e2e run tests/e2e/doubao-computer-use.e2e.ts`。
前置条件：当前仓库的 `src/MyPowerTools.Tests/MyPowerTools.Tests.csproj` 已构建为 Debug；通过 `MPT_E2E_CONFIGURATION` 可指定其他已构建配置。

该文件用 e2e 注册 5 个流程组，通过公共 .NET helper 实际执行 24 个现有产品行为回归。每组验证 TRX 中的精确测试数、执行数和通过数，空筛选或跳过会失败。

| 流程 | 实际执行的内容 | 回归数 |
| --- | --- | --- |
| 健康刷新与模型列表 | 并发刷新合并、三服务状态、模型与 overlay 诊断合并 | 3 |
| 任务与事件流 | 提交请求、SSE 动作与截图、重试与错误、文本上限、取消传播 | 4 |
| Overlay | 鉴权请求、完整动作映射、坐标/时长限制、HTTP 200 语义错误 | 3 |
| Runtime 生命周期 | 自动启动复用、缺少模型密钥、控制器启动/停止/重启 | 5 |
| 配置与偏好 | 秘密原子保存、鉴权拒绝与连接检查、进程环境、外部运行时提示、重新打开后的偏好恢复 | 9 |

HTTP、TCP 状态和 runtime controller 使用隔离 fixture；配置文件落在随机临时目录，并在回归结束后删除。测试执行真实 service 和 view model，覆盖层级为组件流程回归。它们排除了通过读取源码内容验证功能的检查项。

尚未覆盖：开发版窗口内的实际点击/键盘导航、Python 三服务真实启动、真实模型与 MCP 推理、桌面截图和鼠标执行、overlay 实际绘制、用户介入/审批。执行这些流程需要专用桌面会话与测试模型配置。本次测试不会执行用户的真实任务或控制其他应用。

2026-10-03 验证结果：e2e v0.16.0，Windows，Debug；5/5 流程组通过，内部 24/24 行为回归通过，耗时 41.04 秒。本轮覆盖内未发现失败或确认的产品 bug，产品源代码保持原状。桌面 UI 与真实推理验收仍待完成。
