# NSSM Manager 流程验证

执行：`npx e2e run tests/e2e/nssm-manager.e2e.ts --output .e2e/tools/nssm-manager`。

先构建 `tools/nssm-manager/sdk-tool/tests/NssmManager.Tests/NssmManager.Tests.csproj` 的 Debug 配置。e2e 通过真实 .NET 测试宿主调用产品 ViewModel、日志泵、Hook 子进程与兼容层，要求 TRX 中有足够测试数、全部执行、全部通过；源码扫描及环境变量关闭后提前返回的差异测试均未纳入。

| 用户流程 | 自动验证 |
| --- | --- |
| 读取、搜索、保留编辑草稿、新建服务 | 新增 ViewModel 工作流测试，fake 命令边界记录目标和参数 |
| 安装、环境变量、退出规则、Hook 配置 | 先预览确认，再校验、提交；核对序列与完整参数 |
| 应用配置、删除、风险预览与变更后重新确认 | 现有 5 个确认行为测试 |
| 启动、停止、重启、暂停、继续、日志轮转 | 6 个控制命令实例，核对服务名、action 和刷新后的状态 |
| 迁移、回滚 | 2 个命令实例，确认前零提交、确认后单次提交 |
| 规则输入错误、授权取消 | 阻止配置提交、清除 busy、保留可恢复状态 |
| 密码与读取失败 | 密码在加载和新建时清空；读取失败撤销旧编辑状态与待确认操作 |
| 日志输出与日志轮转 | 真实临时文件、时间戳、生产日志泵、共享句柄、轮转阈值 |
| Hook 执行 | 真实隐藏子进程，验证环境传递、退出失败、超时与线程回收 |
| 环境变量编辑、迁移快照 | 双 NUL 数据块、追加删除、展开、快照序列化以及脱离响应信封 |

本次新增 14 个隔离工作流实例，修复两个已由失败测试复现的缺陷：密码跨编辑状态遗留；配置读取失败保留旧编辑对象和确认权限。空服务列表同样清除密码与待确认操作。

这些测试使用 fake runtime 验证 ViewModel 与命令边界、使用真实文件和隐藏子进程验证 I/O 与 Hook。原生 Avalonia 点击、Windows UAC 同意/拒绝、真实 SCM 服务安装删除、实际服务停止顺序、迁移后恢复运行、密码送达提权 broker、完整 Windows 桌面生命周期仍需专用 Windows 隔离环境验收。当前测试保留这些缺口，当前桌面用户服务未参与测试。

报告位于 `.e2e/tools/nssm-manager/report.json`，对应 TRX 位于 `.e2e/dotnet/` 的独立运行目录。
