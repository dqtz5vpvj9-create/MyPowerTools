# Remote Commands 流程验证

执行：`npx e2e run tests/e2e/remote-commands.e2e.ts --output .e2e/tools/remote-commands`。
先构建 `tests/PersonalUx.Tests/PersonalUx.Tests.csproj` 的 Debug 配置。e2e 包装真实产品回归，读取 TRX，要求每项全部执行、全部通过且数量匹配；零测试、跳过或失败均使流程失败。

| 流程 | 自动验证 |
| --- | --- |
| 首次初始化、选择命令、本地文本转换 | 从空临时目录初始化默认目录，执行 prefix 转换并校验完成、输出、历史；所有六种本地转换已有契约回归均纳入 e2e |
| 双输入上传与远程执行 | 受控进程执行器读取真实临时输入文件，校验主机、SSH 命令和 file1/file2 协议，返回输出 |
| 上传失败 | 返回上传退出码 9，确认停止执行且删除临时文件，仍尝试远端清理 |
| 非法 SSH 主机 | 空主机、空格、OpenSSH 选项拒绝且执行器调用为零 |
| 取消 | 上传后取消，确认异常、删除本地文件、远端清理使用有效令牌 |
| 远端失败 | 退出码 17，显示 error、释放忙碌状态、保留错误输出、历史没有成功记录 |
| 重跑 | 恢复原始主机、双输入、显示状态、输出并新增历史；删除命令后拒绝重跑 |
| 未支持本地命令 | 报告映射错误，释放忙碌状态，保留已有历史 |
| 历史查询、恢复、清除 | 大小写查询、空结果、恢复双输入、清空输出、显式清除持久历史 |
| 会话和设置 | 保存并新建 ViewModel 验证主机、选择索引、双栏；保留上限、索引、主机去重/规范化 |
| 命令目录编辑 | 无效命令类型被拒绝，原始文件完整保留 |
| 损坏历史恢复与保留 | 损坏 JSON 保持原样；显式清除后可追加；12 条裁剪为最新 10 条 |

## 修复

上传退出码过去被忽略，失败上传后仍执行 SSH 命令。现在失败会抛出错误并清理。
远端退出码过去被 ViewModel 忽略，失败显示完成且写入成功历史。现在显示执行失败，保留诊断输出并释放忙碌状态。
执行器增加主机校验，在创建临时文件、上传或清理之前拒绝非法值。并发 stdout/stderr 写入累计输出时使用锁保护。

## 覆盖边界

本套件覆盖产品服务和 Avalonia ViewModel 的行为，使用真实临时文件与真实持久化。SSH/scp 边界由受控执行器驱动，避免对用户主机执行命令。
本轮未覆盖真实 SSH 服务器认证、网络断连、远端 conda 与脚本依赖、系统外部编辑器、桌面鼠标/键盘和对话框视觉布局。e2e 当前 web/mobile 引擎无法直接操作 Avalonia 原生窗口，服务回归通过不代表这些桌面交互已经完成验收。
