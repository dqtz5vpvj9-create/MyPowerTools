# 输入法管理器流程验收

运行：`npx e2e run tests/e2e/ime-manager.e2e.ts`。先执行根目录 e2e 准备构建，测试使用 Debug 已构建组件，TRX 要求非零执行、全部通过且无跳过。

| 流程 | 自动化断言 | 层级 |
| --- | --- | --- |
| 标识解析 | 键盘布局、文本服务、0x 前缀规范化、无效输入、注册表 assembly 值往返 | 真实 Core |
| Runtime 进程协议 | health 成功、当前 Windows 用户快照只读返回、无效 JSON、重复字段、未知命令、未知参数、布尔类型及非法 apply 拒绝 | 真实 dotnet 子进程 |
| 编辑启用列表 | 添加、移动、默认项、删除、至少保留一种 | 真实 Planner |
| 应用变更 | 启用、禁用、顺序、默认项、快捷键及系统通知调用 | 真实 Catalog + 受控系统适配器 |
| 初始化和刷新 | 已启用列表、默认标记、脏状态、管理文件落盘 | 真实 ViewModel + 临时数据目录 |
| 添加和筛选 | 未选择时打开面板、无结果、忽略大小写、选中添加、候选排除 | 真实 ViewModel |
| 默认和快捷键 | 设为默认、取消启用、快捷键及 Win+空格映射提交、结果回读 | 真实 ViewModel + 受控 Runtime |
| 放弃 | 列表顺序、勾选、快捷键、映射和脏状态恢复、管理顺序持久化 | 真实 ViewModel |
| 空列表保护 | 全部反选后拒绝应用，Runtime 写入次数为零 | 真实 ViewModel + Planner |
| 故障恢复 | 应用失败保留草稿、读取失败释放忙碌状态、下一次刷新恢复 | 真实 ViewModel |
| 管理范围 | 禁用后继续显示，损坏 JSON 恢复，非法和重复项过滤 | 真实 ViewModel + 临时文件 |

这些测试运行产品组件及命令行为；系统写入由受控适配器承接。测试运行不会修改当前用户的输入法、注册表或全局快捷键。

待真实桌面验收：Avalonia 页面点击与键盘焦点、Windows TSF/注册表实际写入及回滚、打开窗口与新窗口的切换行为、Win+空格映射的提权授权和全局按键、全部键盘布局开关与远程会话兼容。当前 e2e tools-only 目标没有原生 Windows 桌面驱动，上述项目未获得自动化 GUI 验收证据。

回归修复：移动输入法后“放弃”必须恢复已保存启用顺序并将管理顺序同步落盘，避免界面保留草稿顺序同时清除脏状态。
