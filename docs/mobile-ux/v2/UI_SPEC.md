# 预期 UI 与交互规范

设计来源：用户已经认可的 .lavish/mpt-mobile 视觉方向，保留浅灰底、清晰文字、蓝色主操作与克制圆角。文件助手采用熟悉的聊天会话密度与设备选择方式。页面稿是 .lavish/mpt-mobile-v2/index.html；旧应用的大卡片布局不是参考基线。

## 1. 尺寸与视觉变量

以下尺寸均为逻辑 dp，文字为平台逻辑字号，不能把截图的物理像素直接当布局尺寸。Android 必须计入系统安全区和键盘，桌面使用同一语义、适配宽度。

| 项 | 规定 |
| --- | --- |
| 页面底色 / 内容 / 主色 | #F6F7F9 / #FFFFFF / #0965EE |
| 主文字 / 次文字 / 分隔线 | #1C2025 / #69737F / #E5E8EC |
| 页面左右间距 | 16；320 宽度可降至 12 |
| 一级页标题 / 详情标题 / 正文 / 辅助 | 26 / 18 / 15 / 12，随系统字号缩放 |
| 顶部导航 | 56 高；标题一行；返回和更多各至少 44×44 |
| 一级底栏 | 内容 56 高，另加底部安全区；详情会话内隐藏 |
| 最小点击区域 | 44×44；触控区域不得互相重叠 |
| 普通列表行 | 64–76 高；最多两行正文/副标题，内容超出允许自然增长 |
| 消息气泡 | 最大宽度 82%；内距 10–12；圆角 14；无外层重复大卡 |
| 短文字记录 | 1 行正文加状态通常不超过 68 高，不能靠固定高度裁剪长文字 |
| 文件消息 | 名称最多 2 行，大小与状态一行；通常 76–96 高 |
| 输入区 | 单行基础高 56–64；最多 4 行输入；附件队列额外高不超过 96 后内部滚动 |
| 目标选择底页 | 紧凑设备列表，最多占安全区内 70% 高；设备行不做高大瓷砖 |
| 图标 | 20–24 的矢量图形；不能用会缺字的 Unicode 字符充当核心图标 |
| 阴影 / 动画 | 只为层级服务；默认无持续装饰动画；减少动态效果设置生效 |

390×844 的会话在无键盘、无附件时，应能同时展示至少 5 条短文字或 4 条标准文件记录。此条用于发现浪费空间，不允许通过缩小到不可读字号或裁掉文字达标。

## 2. 页面 P01：常用

从上到下：紧凑问候与设置入口 → “文件助手”主入口（最近一句/最近文件名） → 收藏工具网格或列表 → 最近真实操作。没有收藏时只显示一行说明和“添加常用”，不留半屏空白。

文件助手卡片不出现 indexed，不解释“已交给模块”。首页入口文案为“文件助手”；独立“发文件”快捷动作应直接进入附件选择，取消则回会话，不把一个同名按钮当作无区别导航。

已添加设备可显示在一个可纵向滚动的简洁区；不把“添加设备”挤到横向滚动区外。未知连通性只显示设备名，不把“尚未检查”重复贴在每个日常入口上。

## 3. 页面 P02：文件助手

顶部左返回，中间“文件助手”，右更多；其下是 36 高目标行：“发给 文件传输助手 ▾”或“发给 LIS-IMAC ▾”。用户随时知道下一次发送的接收范围。会话记录可保留混合历史，但每条定向记录必须标明接收方；本阶段不伪装成已经实现独立聊天联系人数据库。

消息区占剩余空间。自己的发送靠右，接收靠左，日期集中显示，连续同来源无需重复长说明。文件整行可打开；状态在气泡下或行内，不另套卡片。每条操作菜单放在长按/更多入口，不让“转发到设备”独占一行。

底部仅“＋ / 输入框 / 发送”。空草稿发送禁用，目标选择仍可用。“重新同步”、网盘、Tailnet、服务端地址不出现在日常会话；诊断放右上更多里。

首次自己会话未关联时，在消息区顶部展示一次可折叠提示和“连接我的设备”。不能再叠一个全屏配置向导。选择普通配对设备时该提示隐藏，避免误以为给别人发送也要共享自己的会话。

打开页面默认到最新消息；用户主动上翻阅读时不被回执/状态更新拉走，出现新消息提示，点击才到底部。用户自己发送后定位到新条目。键盘、回执换行、图片加载改变高度后，如果原本处于底部则继续贴底。

## 4. 页面 P03：选择发送目标

顶部“发给谁”，右关闭。第一行“文件传输助手 / 在已关联设备间同步”，随后已配对设备，再是“添加设备”。已有设备在打开页的第一帧显示；旁边最多展示准确的“已连接”或“可发送”，不凭未知结果写离线。

发现新候选只在列表下补充，不让发现遮挡已配对项。选择一行后关闭底页，目标行更新，草稿保留，尚未发送。未配对候选进入授权流程，不能直接后台授予权限。

无设备时仍有“文件传输助手”和“添加设备”；提示“扫描另一台设备的连接码”，不要求同一网络。

## 5. 页面 P04：添加/连接设备

一个主入口“添加设备”，进入后先说明用途：

- “发送文件到另一台设备”：普通配对，扫码或粘贴，预览名称，确认文件互传权限。
- “连接我自己的设备”：共享自己的会话，明确“这台设备将能查看该会话的文字和文件”，再确认。
- “控制电脑工具”：独立权限入口；与文件连接码不混用。

本机码导出页显示设备名、用途、二维码、复制按钮。二维码不能被 toast 或底栏覆盖；长码文本默认折叠。复制反馈在顶部轻提示，不遮挡码。无法扫码时粘贴始终可用。错误码保留输入并就地说明。

## 6. 页面 P05：附件选择与发送

点“＋”打开两项操作：“文件”“照片”。采用系统原生选择器。返回后输入栏上方出现紧凑附件队列，显示名称、大小、移除；复制中显示实际状态。无需再次点击一个“确认已复制”按钮。

目标始终可见，发送后队列清空但记录立刻加入消息区。主按钮不随网络在线情况禁用；只有未准备好内容、无权限目标、正在本地提交等真实原因可以暂时禁用，并给出原因。

## 7. 页面 P06：离线、失败、收件

离线说明放在相应消息上，不占会话大横幅。中转接受显示“已暂存”，本机断网显示“等待网络”，收到回执才“已送达”。失败记录旁一个小型重试动作；详情显示可理解原因及修复入口。

收到图片先缩略图，点开查看；收到文件整行点开。打开系统查看器返回后保留原位置，键盘可再次输入。单次失败不能遮住其他消息或把整页替换为报错。

## 8. 页面 P07：工具库与详情

工具库顶部搜索，下方“全部 / 手机可用 / 电脑工具 / 已收藏”。按稳定产品 ID 去重。工具行包含矢量图标、名称、用途、必要能力说明和独立收藏按钮。可用工具不重复堆“可用”标签，暂不可用说明具体原因。

详情页标题下必须写实际执行设备。手机本地工具直接打开原生 Surface；电脑工具选择授权电脑后再展示该电脑实际能力。缺少远程控制授权时提供“连接电脑”，不能一按按钮假弹“执行完成”。

远程通知页：通知列表支持来源筛选、时间、可读预览；点开正文与引用块；授权缺失说明准确，设置入口可达。远程命令页：命令列表、目标、执行按钮；运行页显示可滚动输出、运行/退出结果、停止；键盘不遮挡参数。电脑任务页复用同一返回、设备标识、操作反馈规范。

## 9. 页面 P08：设备与动态

设备页分“本机”“已添加设备”，每行点击进详情；详情区分文件权限、自己的会话成员身份、工具控制权限，不能合并成一个模糊“已连接”。移除只处理明确范围，保留历史本地文件。

动态只显示真实事件。点击文件事件打开对应记录，命令事件打开运行详情。completed、running 等内部枚举统一映射为中文，未知值显示“状态暂不可用”且记录诊断，不原样漏给用户。

## 10. 响应式、可访问性与桌面

320、360、390、430 宽度及横屏均无横向页面溢出；字号 1.3/1.5 倍可读、主操作可达。键盘出现时输入区在其上方，详情页不再另留一级底栏。滚动容器只有真正需要滚动的内容区，不在竖直 ScrollViewer 内嵌无界消息列表。

宽屏桌面使用可读的最大会话宽度或会话/设备双栏；保持原有桌面菜单和工具入口。不能把 390 宽手机内容拉成满屏超宽卡片。桌面拖入文件进入草稿，支持粘贴；Windows Input Monitor 休息弹窗不在本次改动范围内。

所有核心操作有可访问名称；按钮不可只靠颜色说明状态。长按菜单有可访问替代入口。焦点恢复到之前的编辑位置，底页关闭不丢输入。深色主题使用语义色，不产生白底白字；真实截图验收而非只检查资源键存在。
