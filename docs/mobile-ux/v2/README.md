# MPT 手机版 V2：实现规格与验收入口

状态：2026-09-28 编写；这是待实现规格，不是已完成功能声明。用户已要求先细化文档，再照文档实现。无需再次等待批准才能开始已授权工作。

目标是把整个 MyPowerTools 迁移为适合手机的产品，复用现有模块、命令、权限、事件、设置和跨平台宿主。文件助手是首要打通的日常任务，不是另做一个独立文件 App。

最新文案约定：默认目标显示“文件传输助手”，具体设备显示设备名。不使用“自己”作为目标名称；此次仅修正文案，其余流程不变。

## 交付纪律

- 每个验收项单独记“未实现 / 已实现未验收 / 通过 / 失败 / 环境未覆盖”。没有“差不多可用”。
- 页面稿通过不等于应用通过，单元测试通过不等于跨设备流程通过。
- GPT/Claude 负责界面与交互；后端可由 DSH 按明确合同并发实现。主代理负责实际界面验收。
- 只修改既有仓库，不新增另一套移动应用或模块底座，不创建未经要求的 worktree。
- 每阶段保留可运行代码，但只有对应用户流程走通后，才更新完成状态和发布说明。
