# 功能规格

## 1. 产品与平台

Windows、macOS、Android 共享工具定义、命令、设置、权限、事件和状态语义。设备专属能力通过平台实现或明确授权的远程调用提供。手机版不能把桌面窗口缩小后当作适配完成，也不能把所有桌面工具换成不可点击的占位列表。

本轮实现分为三个连续里程碑：M1 完整文件助手与移动壳；M2 所有已具备手机实现的工具；M3 电脑工具的移动控制面。阶段名表示实施顺序，不能把 M1 宣称为整个手机版迁移完成。

## 2. 信息结构

| 入口 | 包含内容 | 用户可以完成的动作 |
| --- | --- | --- |
| 常用 | 文件助手快捷入口、真实收藏、最近的真实操作 | 继续会话、发文件、打开常用工具、重开最近任务 |
| 工具 | 产品级去重列表、搜索、按实际执行位置筛选、收藏 | 在手机打开本地工具，选择已授权电脑运行电脑工具 |
| 设备 | 本机身份、已添加设备、添加设备、设备权限 | 扫码或粘贴连接码、查看权限、移除设备、查看自己的会话成员 |
| 动态 | 实际任务与传输事件，按时间排序 | 进入对应内容、查看错误、重试可重试任务 |
| 设置 | 主题、存储、通知、后台行为、版本、诊断 | 管理手机设置；高级网络与网盘配置仅在这里或工具设置内 |

进入文件助手或工具任务页后，使用完整详情页及明确返回按钮；任务页隐藏一级底栏，避免底栏、输入栏与系统键盘争抢空间。返回保留草稿、目标和滚动位置。

## 3. 文件助手的两种用途

### F01 文件传输助手

默认目标为“文件传输助手”，含义是自己的共享会话，不是附近随意一台设备。首次打开即可写文字、加附件；完全断网也可本地保存。尚未关联其他设备时，仅有一条轻量说明“内容保存在这台设备，连接自己的其他设备后可同步”，附“连接设备”。此说明不禁用编辑、附件选择或发送。

发送接受后先显示“已保存到本机”，公网接受后显示“已同步”；仅有中转接受不显示“其他设备已收到”。有自己的设备保存回执后，在详情里列明哪些设备已收到。关联动作是用户主动将另一台自己的设备加入会话，必须先预览共享范围并确认。

### F02 发给另一台设备

用户在标题区点目标名称，选择一台已配对设备。选择只改变发送目标，不立即发送。输入和附件保留；按钮始终为“发送”，无内容时不可用。点发送后本地排队，目标显示在消息详情中，不因重新进入界面丢失接收方。

已配对设备即使不在线、没有直连地址，也可选、可排队。后台选择可用路径，不能要求用户先连接 Tailscale、同一 Wi-Fi、填 IP 或切换传输模式。

### F03 首次添加设备

目标选择页始终提供“添加设备”。流程是：添加 → 扫描对方连接码或粘贴 → 预览设备名称与“允许文件互传”范围 → 确认添加 → 返回目标列表并选中该设备。扫码与粘贴共享相同解析、预览和授权逻辑。

生成本机连接码完全本地完成，断网可展示、复制。码中不携带本机网络可用性结论。普通配对不加入自己的共享会话，不授予远程执行工具的权限。添加失败保留输入，给出可操作原因，不丢草稿。

同名设备用平台与稳定设备标识后缀区分；不能用机器名称作为身份主键。重复添加同一设备更新其允许更新的候选信息，不产生重复列表项。旧码兼容；缺少公网投递能力时针对该设备明确要求更新连接码，不能伪装成已可公网送达。

### F04 文字、文件与图片

文字可直接输入、粘贴；输入区根据内容增长至 4 行，再内部滚动。手机回车换行；发送只能由明确发送按钮触发。桌面 Ctrl/Cmd+Enter 发送，Enter 默认换行。

“＋”包含“文件”“照片”。系统选择器取消不改变草稿；选中多个文件后显示紧凑附件队列，逐项移除，保留文件名与大小。选中不立即发送。复制附件到应用的进度真实显示，尚未取得可持久读取内容的附件不能被伪称为已准备好。

系统分享文字、一个或多个文件进入同一个待发送区，默认目标为自己；在用户点击发送前不传输。与已有草稿合并时保持内容可见，不静默替换、丢弃或立即发送。分享带入的内容必须显示来源已准备完成或具体失败项。

### F05 收件与打开

收到文字直接可读；收到文件显示名称、大小、来源、时间和真实状态。整张文件行可点开，打开动作无需另找一枚很小的文字链接。尚未下载时点击启动下载并显示进度；完成后打开。没有可用查看器时提供保存到下载目录或系统分享，不仅显示路径。

交给 Android 查看器后返回，原会话与草稿保留，点击、滚动、输入立即可用。保存到下载目录使用副本，不能删除会话原件。敏感 URI 授权限于实际交给查看器的文件与读取权限。

### F06 消息操作

长按或消息“更多”菜单提供：复制文字、转发、保存副本、查看详情；尚未完成的条目提供取消，失败项提供重试。转发先选目标再确认，复用本地内容但产生新的发送记录。取消不能把已经送达的记录改成取消成功。移除本机记录与撤回远端不是一回事，文案不可混淆；未实现远端撤回时不出现“撤回”。

### F07 离线、重试与进度

| 条件 | 展示 | 自动行为 | 可操作项 |
| --- | --- | --- | --- |
| 本机无网络 | 等待网络，内容已保存 | 恢复后继续 | 取消、详情 |
| 正在上传 | 发送中及真实进度 | 队列推进 | 取消 |
| 中转保存、目标无回执 | 已暂存，等待对方接收 | 继续等待真实回执 | 详情 |
| 目标实际保存 | 已送达 | 停止该条重试 | 打开、转发、详情 |
| 接收到本机 | 已接收 | 不重复下载 | 打开、保存副本 |
| 暂时服务故障 | 等待重试 | 有界退避，网络恢复继续 | 立即重试、取消 |
| 授权失效 | 需要重新连接这台设备 | 不无限快速重试 | 重新添加、取消 |
| 空间不足/内容超限 | 说明限制与下一步 | 不伪装成功 | 清理后重试或移除 |

普通页面不出现堆栈、HTTP 状态码、网卡地址、模块名。详情页可查看脱敏诊断。用户无需点“同步”才能收件；手动检查仅作为详情里的诊断操作。

### F08 路径与网盘

身份与授权独立于路径。每次传输的可达性属于本机与目标之间的一条候选路径，不能把“Tailscale 可用”当成本机或目标的永久属性。

已有直传路径可加速；默认公网投递由 proxy.lixinrui000.cn 提供，直传失败不能阻塞它。公网暂时不可达时本地队列保留。Tailscale 经 DERP 可达也算路径可用，不能等同离线。网络详情按目标和观测时间记录结果。

OpenList 是可选存储：沿用已配置实例或由 MPT 管理安装与运行；添加国内网盘时只完成必要的网盘授权。配置网盘不成为首次发送的前置步骤。既有自定义存储失败时明确显示“自定义存储暂不可用”，不静默将用户选择只存私有网盘的内容改传公网；允许用户明确选择恢复默认公网，并保留现有配置以便返回。

### F09 后台、重启与省电

关闭页面不清空队列；进程重启后从持久状态恢复。Android 受系统后台限制时给出真实提示，不保证已被系统停止的进程仍然即时收件。用户禁用工具后其监听、长轮询和后台任务全部停止；仅暂停接收不禁止用户发送。闲置时等待事件，不为了显示在线状态持续刷全列表。

## 4. 工具迁移与执行位置

工具列表展示稳定产品身份，平台实现 ID 仅在内部使用。已有清单中的每一项都必须有相应移动布局或明确的电脑执行入口，不能拿一个“unsupported”标签完成迁移。

| 产品 | 手机目标体验 | 本轮实现顺序 |
| --- | --- | --- |
| 文件助手 | 本地完整会话、附件、设备选择与收件 | M1 |
| 远程通知 | 本地通知历史、详情、配置和权限；与 NotifyApp 协议保持一致 | M2 |
| 远程命令 | 手机上管理并执行已配置命令/SSH，真实输出、停止、历史 | M2 |
| 进程监测 | 明确是手机自身可见进程还是授权电脑进程，不能混称 | M2 能力核对后接线 |
| 图片快传 | 本地支持时提供分享/选择图片上传；否则明确在电脑执行 | M3 |
| 输入监测 | 查看授权电脑的使用统计、设置与休息提醒；保留 Windows 弹窗修复 | M3 |
| 屏幕舒适 | 操作实际执行设备的亮度/色温；不是远程桌面 | M3 |
| 输入法管理 | 授权电脑上的应用规则与输入法设置 | M3 |
| 卡顿清理 | 电脑目标、扫描结果、明确选择后执行和真实结果 | M3 |
| 服务管理 | Windows 目标、服务列表、详情、启停状态 | M3 |
| 温度管理 | 真实设备配置、温度/露点趋势、控制结果 | M3 |
| ADB 转发 | 授权执行设备上的映射列表、创建/停止、实际端口状态 | M3 |
| 豆包电脑助手 | 电脑目标、任务、进度、停止和实际结果 | M3 |
| 其他已安装工具 | 沿用产品目录；不硬编码成手机可用；按真实能力提供入口 | M2/M3 按平台 |

远程控制采用独立控制配对和授权；文件互传码不得赋予执行命令、启停服务等权限。电脑不在线时不伪装执行成功。危险操作沿用原模块要求，不以手机版简化为理由取消确认或权限检查。

## 5. 全局状态与内容

工具可用性、安装状态、运行状态、最近操作结果分开。indexed 只是目录内部状态，不应给用户显示；unsupported 的具体原因转换为“在电脑上使用”或“此设备暂不支持”，并给出对应路径。连接失败不等于工具未安装。

所有页面使用真实记录；演示设备、Fixture PC、示例文件不得进入出厂数据。验收数据与用户数据隔离。收藏按稳定产品 ID 存储，升级保留；同一产品的手机和电脑实现不产生两个同名收藏。
