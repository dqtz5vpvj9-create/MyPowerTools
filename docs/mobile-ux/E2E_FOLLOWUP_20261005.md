# 手机可用性追加验证

日期：2026-10-05（北京时间）。使用 [tester-army/e2e](https://github.com/tester-army/e2e)，固定 e2e 0.16.0、@e2e-dev/mobile 0.9.2、agent-device 0.21.20。源码基线 093fca0；手机继续使用首轮从 81a4240 构建的 0.2.9/code11 QA 开发包。本轮修改仅涉及测试及报告，未替换 APK、修改线上配置、发布版本或发送邮件。

## 结论

**收发及恢复场景有有效通过证据，但整体验收仍不通过。** 本轮新增 6 项功能诊断通过，1 项设置入口定位测试失败；另外完成 1 项三轮画面采集，人工审图发现一次瞬态文字重叠，不能把采集脚本的绿色结果当作视觉验收通过。全部功能诊断需要区分坐标补偿与原始无障碍操作。

使用用户指定的两台 Pixel 4a：08191JEC213478（10.33.0.145:15557）执行收发及生命周期；08111JEC207803（10.33.0.145:15558）执行只读页签/设置导航。两台硬件序列号在本轮重新核对。没有清除应用数据、改动用户偏好或操作 Windows 桌面。收发使用原专用 QA 会话，未接入日用共享会话。手机草稿在开始时必须为空，输入仅为 MPT-E2E 标记；收发结束后清空测试草稿。

## 未解决问题

- 无障碍控件边界与实际触点不一致。头像边界被报告为 x=915、y=136、width=121、height=15；实际可点击位置为 (975,225)。原始首页语义点击失败仍保留。没有确认根因属于应用、Avalonia 或 agent-device。
- 原生 fill 路径仍校验失败。键盘事件的成功说明发送功能有可用路径，不能据此声称 fill/TalkBack 等辅助路径已修复。
- 附件菜单的可访问按钮名称仍为 Avalonia.Controls.Grid；首轮已记录。
- 截图复现瞬态文字重叠。证据为 render 套件 001-launch-0-immediate.png，比较 002-launch-0-500ms.png 和 003-launch-0-settled.png。采样之间包含驱动截图时间，不能据此给出精确缺陷持续时长。生命周期重启截图也观察到类似画面；尚未定位成因。

首轮 5 项传输/恢复测试和 123 秒闲置 CPU 测量记录见 [首轮报告](E2E_AVAILABILITY_20261005.md)，本轮没有重测或把旧结果计作新增通过。

## 复现

私有 QA 连接码文件不得提交仓库；使用专用手机，保持正常语义点击/fill 套件与补偿诊断套件分开。MPT_E2E_DIAGNOSTICS=1 显式启用键盘、进程停止及物理触点诊断；未启用时这些用例显示跳过，不能计作通过。并发使用不同 MPT_E2E_TARGET，避免默认 e2e-pixel-4a-0 session 绑定冲突。

```sh
MPT_E2E_SERIAL=10.33.0.145:15557 \
MPT_E2E_TARGET=pixel-4a-08191-lifecycle \
MPT_E2E_DIAGNOSTICS=1 \
MPT_E2E_INVITATION_FILE=/mnt/cache/data-cache/mpt-mobile-e2e-20261005/dedicated-invitation.private \
MPT_E2E_TOUCH_OFFSET_Y=136 E2E_TELEMETRY_DISABLED=1 \
TMPDIR=/mnt/cache/data-cache npm run test:mobile -- \
  tests/e2e/mobile-lifecycle.e2e.ts --output .e2e/mobile-08191-lifecycle
```

各表格对应测试文件为 mobile-lifecycle、mobile-shell、mobile-settings-point、mobile-offline-receive、mobile-render，均在 tests/e2e 下。头像实际位置诊断固定于本轮 Pixel 4a 分辨率；不泛化到其他设备。

原始截图、控件树及 JUnit/JSON 报告留在上述忽略提交的本地目录；补充原始数据在 /mnt/cache/data-cache/mpt-mobile-e2e-followup-20261005，不上传连接凭据和设备通知。
