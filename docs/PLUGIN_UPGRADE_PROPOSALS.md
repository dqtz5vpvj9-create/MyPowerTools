# 插件功能与 UI 升级建议

审查日期：2026-08-19  
方法：逐个插件读取全部 Surface View/ViewModel 源码，从产品和 UI 设计角度评估功能完整性和升级空间

---

## 跨插件共性问题

三个模式在多个插件中反复出现：

1. **ViewModel 中已实现但 AXAML 中未接线的代码**——Lag Cleaner 的 `CancelScanCommand`、Input Monitor 的 `CaptureToggleCommand`、SmartBird 的 `IsStale`/`StalenessWarning` 都已实现但从未绑定到 UI。这些是最低成本的升级。
2. **无暗色主题**——Input Monitor 全部硬编码颜色（白底卡片、#F4F6F9 背景、黑色 tooltip）、Paste Image 全部硬编码浅色值、SmartBird WebView2 和 Doubao 截图预览也缺主题适配。
3. **数值输入用纯文本框**——SmartBird、Remote Commands、Lag Cleaner 对温度、端口、时间等数值字段使用裸 TextBox，校验只在提交时才做。改为 NumericUpDown 或加行内校验可在输入时就阻止错误。

## Remote Notifications（远程通知）

### 现有功能
通知收件箱（最新在前）、标签过滤芯片条、文本搜索、全部清除（带确认）、双击打开 Markdown 详情窗口、右键复制、会话链 Prev/Next 导航、连接状态展开器、Windows toast 推送、`mypowertools://` 深链接激活、设置面板（协议/主机/端口/频道/轮询间隔/SSH 密钥/横幅开关）

### 关键缺口

| 级别 | 问题 | 影响 |
|------|------|------|
| 必要 | 无单条消息已读/未读区分 | 所有卡片看起来完全一样，无法一眼看出哪些是新的 |
| 必要 | 无单条删除 | 只有"清除全部"，用户不能只删一条 |
| 必要 | 硬编码颜色不适配主题 | 图标背景、状态指示器用 hex 字符串，暗色主题下是亮斑 |
| 建议 | 无严重度/类型过滤 | 消息有 info/warning/error/success 类型但仅用于显示，不能按类型筛选 |
| 建议 | 无紧凑视图 | 每条卡片最高 160px 预览区，大量通知时滚动距离过长 |
| 建议 | 无 toast 开关 | 不能独立关闭 OS 级弹窗而只保留收件箱 |
| 建议 | 无声音选项 | toast 硬编码 `silent="true"` |
| 建议 | 右键菜单只有"复制" | 缺少"打开""删除""复制会话 ID" |
| 建议 | 详情窗口不显示来源客户端和接收时间 | 数据在 record 上存在但未展示 |
| 打磨 | 500 条上限静默丢弃旧消息 | 用户不知消息被删，无提示也不可配置 |
| 打磨 | 搜索/错误图标用文本字符（⌕、!） | 跨字体环境渲染不一致 |

### 优先升级建议
1. **已读/未读标记 + 标为全部已读**——在 `RemoteNotificationMessageViewModel` 加 `IsRead` 属性，卡片用粗/正常字重区分，双击打开即标记已读
2. **单条删除**——右键菜单和详情窗口加删除入口
3. **主题适配**——将 ViewModel 中的 hex 颜色迁移到 `MptBrush*` 动态资源

## ScreenEase（屏幕调节）

### 现有功能
护眼色温/亮度滑块、7 内置 + 自定义配置文件、日/夜切换调度、番茄钟休息提醒、平滑过渡设置（flag 存在但驱动未实现）、软光遮罩覆盖层、CareUEyes INI 导入、8 个快捷键（只读展示）、诊断面板（显示器信息）、三档响应式布局

### 关键缺口

| 级别 | 问题 | 影响 |
|------|------|------|
| 必要 | 无配置文件删除 | 用户创建的自定义配置无法移除，会越积越多 |
| 必要 | 无逐显示器独立控制 | API 层 `displayId` 参数已存在但 Surface 层固定传 "all"；混合显示器用户无法差异化调节 |
| 必要 | 平滑过渡未实现 | UI 里有过渡时长设置，注释自述"驱动按原实现立即应用"——flag 存在但 gamma 写入是原子性的 |
| 必要 | 主内容区无 ScrollViewer | 展开诊断面板时小窗口下内容被裁切 |
| 建议 | 无规则管理 UI | `ScreenEaseRule` 数据模型已支持条件触发（如"app X 聚焦时切换配置"）但无 UI |
| 建议 | 遮罩颜色用 hex 文本框 | 用户需知道色值才能操作，应改为可视拾色器 |
| 建议 | 日出/日落用纯文本输入 | 无时间选择器，校验只报错不引导 |
| 建议 | 配置文件无复制功能 | 创建变体需手动对齐滑块 |
| 建议 | 快捷键只读展示 | 无法在插件内编辑快捷键手势 |
| 打磨 | 休息提醒到时无通知/声音 | 番茄钟阶段静默切换，用户在后台时注意不到 |
| 打磨 | 无设置导出 | 有 CareUEyes 导入但无通用导出 |

### 优先升级建议
1. **配置文件删除按钮**——侧栏每个配置旁加删除入口，带确认
2. **逐显示器控制**——Surface 层加显示器选择下拉或标签页，向 API 传具体 `displayId`
3. **实现平滑过渡**——定时器驱动的中间 gamma ramp 插值循环
4. **主内容区包 ScrollViewer**

## ADB Forwarder（ADB 端口转发）

### 现有功能
设备状态总览（有线/Wi-Fi 双表格）、服务状态徽章、设备配置 CRUD（有线设备 ID+端口、Wi-Fi 设备名/地址/端口/间隔）、脏状态追踪+保存、诊断面板（ADB 状态/端口转发状态/错误详情）、响应式双栏布局

### 关键缺口

注：隐藏的 rules/devices/activity 面板和交互式转发工作区是有意废弃的旧实现，不属于缺口。

| 级别 | 问题 | 影响 |
|------|------|------|
| 必要 | ADB 不可用时仪表盘无主动提示 | 设备表格为空但无解释，需导航到诊断才能了解原因 |
| 建议 | 无最后刷新时间戳 | 状态徽章只显示"运行中"/"需要关注"，不知数据何时获取 |
| 建议 | 无单设备连接测试 | Wi-Fi 设备状态来自后台轮询，无法按需探测单个设备 |

### 优先升级建议
1. **ADB 不可用时在仪表盘显示行动指引横幅**——"ADB 不可用，请安装 platform-tools 或检查 PATH"
2. **加最后刷新时间戳**——状态徽章旁或刷新按钮附近显示"最后刷新: HH:mm:ss"

## Paste Image（粘贴图片）

### 现有功能
蓝色信息横幅（工作流说明+快捷键）、上传目标卡片、连接状态检查（OpenSSH+远端主机）、上传按钮+不确定进度条、颜色编码反馈横幅（蓝/绿/红）、最近上传图片预览（尺寸/大小/路径）、最近 5 条上传记录、桌面通知、前台窗口变化检测（跳过快捷键发送）

### 关键缺口

| 级别 | 问题 | 影响 |
|------|------|------|
| 必要 | 历史记录无点击复制 | 路径显示为纯文本，无法复制旧路径——日常最常用的操作缺失 |
| 必要 | 无设置入口或链接 | 页脚提到"Paste Image 设置"但无法导航过去；首次使用时默认值 "chris:/tmp" 毫无意义 |
| 必要 | 全部颜色硬编码 | 暗色主题下白底卡片在深色背景上割裂 |
| 建议 | 进度条是不确定的 | 模块内部跟踪了详细耗时（剪贴板读取/SSH 启动/上传/退出）但未展示 |
| 建议 | 不显示快捷键发送结果 | 发送/跳过/失败信息在日志但不在 UI |
| 打磨 | 无响应式布局 | 固定双栏不堆叠，窄窗口下内容挤压 |
| 打磨 | 历史只显示 5 条但存了 20 条 | 可加"显示全部"或滚动列表 |

### 优先升级建议
1. **历史记录行加复制按钮**——单个功能缺失影响日常使用
2. **内联设置区或设置导航链接**——首次使用体验是产品信任的第一关
3. **暗色主题适配**——替换硬编码颜色为 `MptBrush*`

## 豆包 Computer Use

### 现有功能
运行时状态卡片（7 态状态机）、警告横幅（缺运行时/缺 API 密钥/端口安全）、凭证展开器（3 个 masked 密钥+URL+测试连接）、任务面板（模型下拉/指令输入/自动启动/系统提示词/运行-停止-清除）、本地服务面板（逐服务状态行+遮罩调试）、活动仪表盘（4 个指标磁贴+实时截图预览+追踪列表 64 条+JSON/诊断展开器）、进程/端口/日志展开器、响应式布局（3 档）

### 关键缺口

| 级别 | 问题 | 影响 |
|------|------|------|
| 必要 | 运行时缺失时无安装指引 | 只有被动警告"missing"，无安装按钮/步骤/链接 |
| 必要 | 截图预览固定 280px 无缩放无历史 | 视觉代理的核心价值——看到 agent 在做什么——被小预览图严重低估 |
| 建议 | 三个 API 密钥关系不清 | AUTH_API_KEY 需要 AUTH_KEY 且必须匹配，但约束只在保存报错时才暴露 |
| 建议 | "Grounding"指标是未解释的术语 | 无 tooltip 或定义 |
| 建议 | 遮罩调试暴露给所有用户 | 开发级 X/Y/radius 控件与任务运行器并列 |
| 建议 | 任务无进度指示 | 运行中只有静态"observing screen..." |
| 打磨 | 追踪列表不持久化 | 内存中最多 64 条，重启即丢失 |

### 优先升级建议
1. **引导式运行时安装向导**——检测前置条件+逐步安装+一键设置
2. **交互式截图查看器**——可缩放/平移+截图时间轴/胶片条+从追踪条目点击跳转

## SmartBird Thermostat（SmartBird 温控器）

### 现有功能
标题栏（在线/离线徽章+模式/制冷/温度/设备数芯片）、WebView2 嵌入控制台（含不可用回退卡片）、设置面板（5 个配置区 ~30 字段：服务/设备、温控策略、天气/回退、能源服务器、邮件通知）、Windows Credential Manager 集成、TCP/HTTP/ADB 连接测试

### 关键缺口

| 级别 | 问题 | 影响 |
|------|------|------|
| 必要 | WebView2 回退只有空卡片 | 浏览器引擎失败时信息密度降为接近零——无温度、无状态数据 |
| 必要 | `IsStale`/`StalenessWarning` 已实现但未渲染 | 属性在 ViewModel 中计算好了但 AXAML 里不绑定——过期数据与实时呈现方式相同 |
| 建议 | 设置页是 ~30 个文本字段的墙 | 无行内校验、无 tooltip、"dew-point margin"和"hysteresis"等专业术语无解释 |
| 建议 | 两步确认不可见 | 首次点击保存只显示状态栏文本，按钮本身不变——极易漏过 |
| 建议 | 设置和控制台互斥 | 调设置时看不到当前读数，保存会重启服务 |
| 打磨 | 高德城市代码是裸数字 | 无查询、自动完成或可读标签 |

### 优先升级建议
1. **原生温度仪表盘卡片**——WebView2 回退时用 `SmartBirdThermostatSnapshot` 数据渲染表面温度（大字）、露点、环境温湿度、制冷开关、设备列表
2. **接线过期指示器 + 自动刷新**——把已实现的 `IsStale`/`StalenessWarning` 绑定到 AXAML，加 30 秒定时刷新

## Input Monitor（输入监控）

### 现有功能
状态条（疲劳百分比+前台应用+采集状态）、4 列汇总卡片（键盘/鼠标/窗口/交互时长）、粒度选择器（日/月/季/年）、维度选择器（全部/键盘/鼠标/应用）、日期导航、分类过滤、7 种图表（活动时长柱状图、频率面积图、小时热力图、周网格热力图、鼠标轨迹热力图（多显示器）、按键热度、应用分类分布+Top15）、30 秒自动刷新

### 关键缺口

| 级别 | 问题 | 影响 |
|------|------|------|
| 必要 | 采集开关未接线 | `CaptureToggleCommand` 已实现但 UI 中无对应按钮——用户无法停止数据采集 |
| 必要 | 完全无暗色主题 | 全部硬编码颜色（白底、#F4F6F9、黑色 tooltip），暗色模式下是刺眼的白色矩形 |
| 必要 | 零隐私控制 | 无按数据类型 opt-out、无留存设置、无数据删除、无应用排除列表——持续记录全部键盘/鼠标/应用活动 |
| 建议 | 无休息提醒配置 | "开始休息"按钮存在但无频率/时长/阈值设置 |
| 建议 | 非日粒度无时间导航 | 月/季/年视图锁定在默认时段 |
| 打磨 | 应用列表限 15 条 | `.Take(15)` 无"更多"或截断提示 |

### 优先升级建议
1. **接线采集开关 + 添加隐私控件**——绑定 `CaptureToggleCommand` 到标题栏，加留存设置和"清除数据"入口
2. **暗色主题**——`DashboardPalette` 改为检测主题，所有硬编码颜色替换为动态资源

## Local Lag Cleaner（本机卡顿专清）

### 现有功能
12 个指标卡片（健康分/CPU/内存/调度/分页/存储/GPU/内核池/句柄/进程线程/空闲/MCP）、8 诊断域（严重度+分数+摘要）、证据&进程选项卡（因果链+进程表+句柄表+文件归因+探针覆盖）、清理计划选项卡（6 个场景按钮+8 位确认令牌+条件复选框+执行结果）、两阶段确认（扫描→审查→生成计划→输入令牌→执行→自动重扫）

### 关键缺口

| 级别 | 问题 | 影响 |
|------|------|------|
| 必要 | 取消按钮未接线 | `CancelScanCommand` 已完整实现但 AXAML 中不绑定——15 秒扫描无法中止 |
| 必要 | 管理员计划复选框是死控件 | `AllowServiceRestart` 显示但 `CanApply` 不检查它——按钮永久禁用 |
| 建议 | 硬编码计划按钮与诊断结果无关联 | 用户需自行把诊断结果映射到 6 个按钮名，无高亮或建议 |
| 建议 | 报告路径是裸文本 | 无"打开"或"复制路径"按钮 |
| 打磨 | 证据表格无排序/搜索 | 8 列进程表只能肉眼扫描 |
| 打磨 | 无回滚 UI | `CleanupPlan` 有 `IsReversible`/`RecoveryPlan` 字段但只渲染为文本 |

### 优先升级建议
1. **接线 CancelScanCommand**——绑定到 `IsBusy` 时可见的取消按钮
2. **修复管理员计划复选框逻辑**——让 `CanApply` 检查 `AllowServiceRestart`，或改为信息横幅+CLI 命令

## Remote Commands（远程命令）

### 现有功能
工具栏行（命令下拉/主机输入/运行-重运行-取消-复制-清除按钮/YAML 编辑器/设置）、工作区面板（Input 1/2 文本输入+输出 TextBox+"在编辑器中打开"）、历史面板（搜索+列表+双击恢复）、状态栏（状态+描述）、YAML 编辑器对话框（单色 TextBox+行内错误）、设置对话框（外部编辑器/默认主机/历史保留/第二输入窗格）

### 关键缺口

| 级别 | 问题 | 影响 |
|------|------|------|
| 必要 | 工具栏 11 列固定宽度 | <1200px 时裁切溢出，无响应式 |
| 必要 | "Input 1"/"2nd input"标签无意义 | 无按命令定义的占位文本或说明 |
| 必要 | 运行中无视觉反馈 | 无 spinner/进度条，只有状态文本 |

| 打磨 | 无键盘快捷键 | 无 Ctrl+Enter 运行、Escape 取消 |

### 优先升级建议
1. **响应式工具栏 + 按命令上下文帮助**——重排为两行，加每命令的 `InputHint` 字段
2. **运行状态指示器 + 连接诊断**——加 ProgressBar 绑定 `IsRunning`，加"测试连接"

## 最低成本最高收益的全局优先事项

以下 5 项只需把已实现的代码接线到 UI，每项改动在 5-15 行 AXAML：

1. **Lag Cleaner — 接线 CancelScanCommand** 到可见按钮
2. **Input Monitor — 接线 CaptureToggleCommand** 到标题栏
3. **SmartBird — 绑定 IsStale/StalenessWarning** 到 AXAML
4. **Lag Cleaner — 修复 AllowServiceRestart 复选框逻辑**
5. **Remote Notifications — 加单条删除到右键菜单**
