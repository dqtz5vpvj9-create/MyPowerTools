# macOS 0.3.21

- Shell 自带矢量图标字体，覆盖当前界面的 Windows 私用区图标，不再要求 macOS 安装 Segoe 字体。图形原稿和生成脚本位于 `scripts/build-shell-icon-font.py`。
- 侧栏加宽至 280，工具标识放大；名称允许换行。首页最近工具把状态放在名称下方，避免状态说明把名称挤成省略号。
- 修正小关闭按钮的最小尺寸和内边距，明确按钮内容的字体，修复刷新、返回及关闭图标。
- macOS 菜单栏使用圆环和独立百分比文字。原来的非预乘透明度位图会使 `NSGraphicsContext` 返回 nil；现在使用 AppKit 支持的格式。
- 额度读取支持 ChatGPT.app 内置 Codex CLI，排除 GUI 可执行文件；请求超时后仍可回退到会话额度。失败时显示未知状态并重试。

## 实机验证

在 Apple Silicon macOS 15.7.7 的完整安装布局中更新并启动 Shell，检查首页、侧栏、工具列表和刷新按钮。所有七个侧栏名称完整可读，快捷图标及关闭按钮可见。

真实额度接口返回 88% 剩余时，原生 NSStatusItem 同时记录标题 `88%`、图像存在、visible=1。该数值随账户用量变化，并非固定演示值。设置 `MPT_TRAY_DIAGNOSTICS=1` 可在启动时查看读取来源及原生控件状态。

`tests/macos/quota-bitmap-smoke.mm` 调用实际原生绘图函数并检查位图包含可见像素。另用挂起的 app-server 进程验证超时后可回退到隔离会话数据。额度解析和平台约定的定向检查通过。

本次处理字体、布局和额度显示；Remote Notifications 后台连接不可用、需要外部服务的工具状态不属于本次已验证修复范围。
